## KAARSHIKA — AGRICULTURAL AI

KAARSHIKA is an agricultural AI system designed to provide intelligent and context-aware assistance for agricultural queries.

The system combines intent classification, Retrieval-Augmented Generation, reinforcement-learning-based action selection, and a Large Language Model.

The overall architecture is:

User query + farm context
→ Intent Router
→ DPR-based retrieval
→ FAISS vector search
→ Reinforcement Learning action scoring and selection
→ Qwen2.5-3B-Instruct
→ Final response

The primary knowledge source for the RAG system is the Package of Practices (Crops) document.

KAARSHIKA uses a DistilBERT-based classifier with PEFT/LoRA for intent classification.

The system also includes a reward model based on DistilBERT with PEFT.

The reinforcement-learning component performs action scoring and selection. The selected action is treated as an important control signal for the subsequent generation process.

The project uses custom prompts and datasets for response generation.

Tanmay implemented the RAG pipeline without relying on LangChain. This gave him hands-on experience with document retrieval, embeddings, vector search, and integrating retrieved information with an LLM.

## MIRA — MINE INTELLIGENCE AND RISK ASSESSMENT

MIRA stands for Mine Intelligence and Risk Assessment.

MIRA is an AI-powered system designed to assist with mine inspection, issue classification, and risk assessment.

The overall system includes:

Inspector mobile application
→ Flask backend
→ MariaDB database
→ Inspection and PDF processing
→ AI classification
→ Risk assessment
→ Regulatory knowledge retrieval
→ LLM-generated explanation

Tanmay's role in MIRA focused on the AI components. Backend development was handled by another team member.

MIRA uses a DistilBERT model with LoRA for classification tasks involving:

* Issue classification
* Category classification
* Severity classification
* Recurrence classification

MIRA also contains a Logistic Regression-based risk engine.

The risk engine does not use reinforcement learning.

The regulatory knowledge component uses Retrieval-Augmented Generation based on the CMR 2017 regulations.

The RAG knowledge base contains approximately 11,726 chunks.

The retrieval pipeline uses DPR embeddings and FAISS.

The generative component uses Qwen2.5-3B-Instruct with LoRA.

MIRA supports English, Hindi, and Hinglish.

The system is designed around local and in-house AI rather than external AI APIs.

Tanmay implemented the RAG components without using LangChain, giving him practical experience with the underlying components of a RAG pipeline.
